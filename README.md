# Recipe Project

CS 452 (Database Modeling Concepts) final project: a recipe sharing app.

## Planned features

- Recipe sharing with "from the kitchen of" credit
- Customizable recipe templates
- Want-to-learn list
- AI-assisted recipe import
- Recipe photos (covers and inline)
- Customizable filters and pages
- Export to PDF
- User profile pages with public recipes
